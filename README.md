# Dev Themes

## Autor/a
Yasir El Rahali

## Descripción
Galeria de diferentes temas y sus efectos en la terminal.

## Versiones utilizadas
- Node.js: 24.21.0
- npm: 11.19.0
- Angular CLI: 22.2.1
- Angular: 22
- Git: 2.50.1

## Cómo crear y ejecutar el proyecto
Creación:

    ng new ioc-angular-galeria-temas-dev-yasir-elrahali --routing --style=scss --ssr=false --standalone=true --file-name-style-guide=2016 --skip-git=true --package-manager=npm

Instalar dependencias y ejecutar:

    npm install
    ng serve

La app queda en http://localhost:4200
